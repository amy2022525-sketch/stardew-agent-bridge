# 星露谷游玩与持续记忆

以玩家目标为准，用真实观察推进游戏。每轮都做到：**读日志 → 看当前世界 → 选短目标 → 行动并核对 → 写短期日志 → 提炼长期记忆**。收益包含少走路、少失败、少重复查询和少用上下文，不只追求金币。

## 开始或接手续玩

1. 确认 MCP 已连接，读取宿主实际暴露的 `stardew_*` 工具定义；参数与能力以工具返回为准。连接问题才用 `stardew_doctor`，不要每步诊断。
2. 读取 `stardew_status`、小半径 `stardew_snapshot`；有 `stardew_context` 时读当前世界/角色/profile 和任务助手状态。先核对身份，再加载对应日志；不能用农场显示名区分不同存档。
3. 按 [日志规则](references/journaling.md) 找到短期检查点、长期目标及当前目标相关的少量经验。先处理未决 actionId / taskId；旧日志是线索，当前状态须重新观察。
4. 用户有目标就沿用；“随便玩”则优先照料现有生产、保留必要资源，再探索一个小目标。参考 [攻略](references/gameplay-guide.md) 对应章节；不强制速通、社区中心或 Joja 路线。
5. 把目标拆成当前地点内可核验的一小段，并记录停止条件、资源预留和回家余量。首次游玩先完成一个短闭环，不一次接管整季。

身份未知时只用当前会话的临时日志，恢复身份后再决定是否合并。发现存档副本、角色或 profile 改变时，不把旧世界的待办/资源当作新世界事实。

## 选择执行方式

按 [工具与执行模式](references/bridge-playbook.md) 操作：

- **直接 MCP**：适合当前能力已支持的小任务。取得己方会话，串行写动作；移动用目标附近寻路，同类低风险动作小批处理，用返回结果或局部观察核对。
- **可选执行模型**：玩家已配置并启用时，给重复作物照料等受支持操作派一个有范围、预算和成功条件的任务；先释放自己的直接控制。主 Agent 负责目标、监督、日志及长期策略。
- 没有执行模型也能用本 Skill 直接玩。不能为了写记忆而自行启用模型、配置密钥或放宽权限。

攻略里的种植、购买、社交、睡觉等建议并不意味着执行模型都能做。当前自动任务仅支持单人及已授权政策；能力不足时缩小任务、转为已获授权的直接模式，或向玩家说明阻塞。

## 行动与复核

- 使用当前快照的真实引用、背包槽位、物品和菜单选项。作物可能以 `kind=soil` 携带 `crop/cropState`；缺少观察覆盖不等于那里没有作物。
- 新动作使用新 actionId；有未知回执时保存原 ID，只查询原收据和观察，不能换 ID 赌重试。取得控制、接单成功、到达地点和任务完成都不代表游戏已保存。
- 不并行发游戏写动作。已有返回证据足够时不再全量截图/快照；换图、换日、菜单变化、引用过期或结果矛盾时重新观察。
- 同样失败且无进展时，改变一个有依据的条件后再试；连续 2–3 次无进展就停下，记录失败条件和替代方案，不做无限循环。
- 玩家 F9 / Web 接管优先；停止自动任务并交还己方控制，不能靠日志、旧授权或自动 resume 绕过停止锁。

## 必须维护两层游玩日志

具体字段、保存方法与恢复流程见 [journaling.md](references/journaling.md)。首次使用时立即选定可写存储；有文件能力可从 [短期模板](assets/short-term.template.md) 与 [长期模板](assets/long-term.template.md) 初始化。它们是模板，不是已经发生的游戏记录。

| 日志 | 写入时机 | 必须保留 |
| --- | --- | --- |
| 短期 | 开始/恢复时、一个小目标或一批动作结束、重要资源动作前后、异常、接管及退出前 | 真实世界/角色、游戏日期时间、当前目标、已核验差分、未决 ID、下一步、停止原因 |
| 长期 | 会话结束或跨日复盘、里程碑、重复失败产生新结论、用户改变方向时 | 长期目标及依赖、资源预留、已确认进展、有条件的经验、待验证假设与到期条件 |

日志必须真的写入并确认成功。没有持久存储时在回复中交付可复制的两层检查点，明确“仅本次聊天，尚未持久化”；不能声称已记住。紧急停止先执行，不能等写日志。

每次恢复只读短期摘要、长期目标和与当前目标有关的几条经验，不重读所有流水。长期日志不能保存临时 targetRef、contextToken、密钥，也不能把计划、推测、模型报告写成游戏事实。

## 每轮收尾

结束或移交己方会话；不要为了写日志额外推进游戏日。确认日志落盘或记忆 API 返回成功，再简短汇报：已核验成果、未决/剩余事项、当前位置与资源风险、下一步及日志位置。若后台任务还在运行，先遵从玩家对继续/停止的要求，并明确它的真实状态。

本 Skill 只是可迁移的 Agent 指令与攻略，不新增 MCP 权限，也不会自动加载到 Bridge 内部执行模型的提示词。主 Agent 要把相关约束和成功条件写入单次派单，不能假设子模型已经读过整个技能。
